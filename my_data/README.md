# Put your own FTIR files in this folder

Copy all your FTIR spectra into this folder, including every replicate. Keep them exactly as the instrument exported them (CSV, TXT, or Excel). Column 1 should be the wavenumber (cm⁻¹) and column 2 the absorbance or % transmittance.

Name the replicates so that the sample is clear, for example:

```
CONTROL 1.csv
CONTROL 2.csv
CONTROL 3.csv
HEATED 1.csv
HEATED 2.csv
HEATED 3.csv
```

Then follow "How to use" in the main [README](../README.md).
